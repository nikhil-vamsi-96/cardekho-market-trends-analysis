# Project Details

## 1. Problem Statement
The used-vehicle market contains vehicles with different manufacturing years, prices, kilometres driven, fuel types, transmission types, seller types and ownership history. The project analyzes these factors to understand vehicle pricing and depreciation patterns.

## 2. Project Description
This project analyzes CarDekho used-vehicle data to identify price trends, vehicle depreciation and market patterns. It examines manufacturing year, selling price, present price, kilometres driven, fuel type, transmission, seller type and ownership to generate useful insights for the used-vehicle market.

## 3. End Users
- Used-car buyers
- Vehicle sellers
- Car dealers
- Automotive companies
- Data analysts
- Students and researchers

## 4. Technology Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- CSV dataset

## 5. Results
The analysis focuses on price variation, depreciation, vehicle age, kilometres driven, fuel type, transmission, seller type and ownership. Visualizations are used to communicate the major market patterns.
